# Referências técnicas — publicações sociais Meta

- A API de Páginas do Facebook permite publicar no feed e agendar posts entre 10 minutos e 30 dias; a publicação requer token da Página e permissões de gestão de conteúdo. Fonte: [Posts — Pages API](https://developers.facebook.com/documentation/pages-api/posts).
- A API do Instagram profissional publica imagens, vídeos, Reels e carrosséis por meio de containers. As mídias devem estar acessíveis publicamente no momento da publicação e o limite informado é de 100 posts publicados por API em uma janela móvel de 24 horas. Fonte: [Content Publishing — Instagram Platform](https://developers.facebook.com/documentation/instagram-platform/content-publishing).
- Vídeos e Reels no Facebook exigem token da Página e upload pela API de vídeo. Para Reels, a documentação informa limite de 30 posts via API a cada 24 horas e fluxo de iniciar upload, enviar o arquivo e finalizar a publicação. Fonte: [Publishing — Video API](https://developers.facebook.com/documentation/video-api/guides/publishing) e [Reels Publishing API](https://developers.facebook.com/documentation/video-api/guides/reels-publishing).
- Para carrossel de imagens do Facebook, a plataforma deve primeiro criar fotos não publicadas e depois criar o post no feed com os IDs retornados em `attached_media`. O fluxo não é aplicável a vídeos mistos no Facebook. Fonte: [Page Photos — Graph API](https://developers.facebook.com/docs/graph-api/reference/page/photos/).
- A Meta exige solicitar apenas as permissões necessárias e pode requerer App Review e verificação empresarial para níveis avançados de acesso. Fonte: [Permissions Reference](https://developers.facebook.com/docs/permissions/).
